# 案件管理系统（法律服务专用）

> 面向法律服务公司（交通事故、工伤、意外险、学平险等理赔业务）的轻量案件管理系统。
> 集**案件全流程管理、电子合同签署、附件云端预览、权限审计、数据备份**于一体，单机 Docker 一键部署，全中文界面，可完全内网运行。

---

## 一、核心优点

| 优点 | 说明 |
|------|------|
| **零代码业务定制** | 案件类型、自定义字段、状态流转全部后台可视化配置，新增业务线无需改代码 |
| **自带电子签章** | PDF/Word 模板上传 → 可视化拖拽签名位 → 一键发起，当事人点链接即可在线签名，单链接支持多人依次签署，自动生成签署后 PDF |
| **数据安全留痕** | 登录与全量数据操作写入审计日志，超管可查改前/改后差异；日志保留期可设置并每日自动清理 |
| **一体化备份恢复** | 支持手动/定时自动备份、保留天数自动清理、一键恢复，数据永不丢失 |
| **细粒度权限** | 超级管理员 / 管理员 / 员工三级角色 + 14 项功能权限点自由勾选；员工默认只见自己负责的案件 |
| **效率工具齐备** | Excel/CSV 批量导入导出、待办提醒、统计看板、员工办案量表、附件整案打包下载 |
| **全中文 · 低依赖** | 前端资源全部本地 vendor（Bootstrap/Chart.js/PDF.js），无外网 CDN，断网可用 |
| **安全加固** | CSRF、XSS（CSP/安全头）、SQL 注入参数化、登录与签署接口限流、强口令策略、优雅停机 |

## 二、技术栈

- **运行时**：Node.js 20（Docker Alpine）
- **框架**：Express（CommonJS）+ EJS 服务端渲染
- **数据库**：PostgreSQL 16（Docker 独立容器）
- **前端**：Bootstrap 5 + Bootstrap Icons + Chart.js + PDF.js（本地 vendor）
- **文档处理**：pdf-lib / pdfkit（PDF 签名与生成）、LibreOffice（Word/Excel 转 PDF 预览）、exceljs（Excel 导入导出）
- **部署**：Docker Compose（app + db 两容器）

## 三、快速开始（Docker 部署）

### 1. 环境要求
- Linux 服务器（建议 Ubuntu 20.04+）或本机 Docker
- Docker 与 Docker Compose v2

### 2. 获取代码并配置
```bash
git clone https://github.com/yuxianglun66-del/case-manager.git
cd case-manager

cp .env.example .env
```
编辑 `.env`，**务必修改以下三项**：

| 变量 | 说明 |
|------|------|
| `DB_PASSWORD` | 数据库密码，改成强密码 |
| `SESSION_SECRET` | 会话加密密钥，32+ 位随机字符串 |
| `MAX_FILE_MB` | 单个附件上传上限（MB），默认 50 |

### 3. 启动
```bash
docker compose up -d --build
```
- app 容器内部端口 3000，默认映射宿主机 `3000`（可用 `APP_PORT=8080` 修改）
- 首次启动自动建表并写入默认数据

### 4. 首次登录
- 访问 `http://<服务器IP>:3000`
- 默认账号：**admin / admin123**
- 登录后系统会强制要求修改密码（生产环境密码可在 `.env` 的 `ADMIN_PASSWORD` 预设）

### 5. 部署域名
登录后进入 **系统设置 → 品牌与主题 → 部署域名**，填写对外访问地址（如 `https://case.example.com`），用于生成合同签署链接等绝对 URL。

### 6. Nginx 反向代理 + HTTPS（推荐）
```nginx
server {
    listen 443 ssl http2;
    server_name case.example.com;
    ssl_certificate     /etc/letsencrypt/live/case.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/case.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
        client_max_body_size 100M;   # 需 ≥ MAX_FILE_MB
    }
}
```

## 四、操作指南

### 1. 工作看板
- 顶部 4 张统计卡：案件总量 / 待受理 / 处理中 / 结案归档
- 柱状图按**案件类型**统计、环形图按**状态**统计
- 管理员可见**员工办案量**排行
- **待办提醒**：工作台自动列出「已逾期 / 今天到期 / 未来 N 天内到期」的流程提醒（提前天数可在系统设置调整），点击「确认」完成提醒

### 2. 案件管理
- **新建 / 编辑**：选择案件类型后动态展示对应字段，带必填校验；可设置负责人（签单/服务人员）、签单日期、收费约定
- **列表**：按案号/类型/状态/负责人/签单日期区间筛选，支持分页
- **详情页分区**：
  - 基本信息 + 自定义字段
  - **当事人**：一案多人，姓名/角色（原告、被告、委托人等）/证件/电话/地址
  - **附件**：多文件上传（图片/Word/PDF/Excel/ZIP 等），图片缩略图墙 + 灯箱，在线预览（图片/PDF 内嵌，Word/Excel 转 PDF），支持替换、删除、整案打包 ZIP 下载
  - **合同**：发起签署、查看签署进度、下载签署后 PDF、撤销/删除
  - **进度时间线**：创建/改状态/编辑/附件/签署等操作自动留痕
  - **下一步流程**：填写下一步动作 + 提醒时间，进入看板待办
- **导入导出**：列表一键导出 Excel / CSV（含当前筛选条件），下载标准模板后批量导入（类型/状态/负责人自动匹配）

### 3. 电子合同签署（核心流程）
1. **上传模板**：系统设置 → 合同模板 → 上传模板（支持 PDF 或 Word）
2. **设置签名位**：点击模板行「铅笔」进入可视化编辑器，在 PDF 上拖拽签名框，可指定签署角色（如「原告」）与文本字段（可插入 `{name}` `{id_card}` `{address}` 等当事人变量，签署时自动填充）
3. **发起签署**：案件详情 → 合同 → 选择模板与标题、勾选签署当事人，系统自动生成签署链接
4. **对方签署**：把链接发给当事人（无需账号登录），同一链接内可多人**依次签名**，签名支持手写绘制，完成后自动合成签署后 PDF
5. **管理**：全程可查看签署进度，支持撤销（重新发起）与下载归档

### 4. 用户与权限
- **用户管理**（管理员）：新建用户（用户名/姓名/角色）、编辑、停用、彻底删除（案件保留可改派）、重置密码、设置密保问题
- **角色与权限**（仅超管）：三级角色 + 14 个权限点勾选配置：
  - 案件：查看全部 / 新建 / 编辑 / 删除 / 指派 / 提醒 / 收费 / 导入导出
  - 当事人 / 附件 / 合同签署
  - 系统：用户管理 / 角色权限 / 系统设置
- **登录安全**：密码 bcrypt 加密、错误锁定/限流、忘记密码走密保问题重置

### 5. 系统设置（仅管理员）
- **案件类型与字段**：新增/停用类型，按类型配置字段（文本/多行/数字/日期/下拉/手机号、必填、排序）
- **案件状态**：自定义状态名称、分类（待处理/处理中/诉讼中/已结案/已归档，用于看板统计）、颜色、排序
- **品牌与主题**：公司名称、Logo、部署域名；亮/暗/跟随系统三模式 + 6 套预设配色一键应用
- **合同模板**：见上方签署流程

### 6. 备份与恢复（仅超管）
- 手动「立即备份」生成 JSON 快照文件，可下载、删除
- 设置**自动备份**：开关、频率（每日/每周）、执行时间、保留天数（超期自动清理）
- 一键**恢复**：从快照文件恢复全部数据（恢复前系统自动断开业务）

### 7. 操作日志（仅超管）
- 记录登录、案件/当事人/附件/合同/用户/设置/备份等**全部数据变更**
- 按用户、操作类型、日期区间、关键词筛选；有变更的条目可展开查看**改前/改后**差异
- 可设置**日志保留时间**（3 / 7 / 30 / 90 天或不清理），系统每日自动清理，也可手动一键清理

## 七、常见问题

| 现象 | 原因 / 处理 |
|------|------|
| 登录后跳回登录页 | `.env` 中 `SESSION_SECRET` 不一致，或 Nginx 未配置 `proxy_set_header Host $host` |
| 附件上传 413 | Nginx `client_max_body_size` 需 ≥ `MAX_FILE_MB` |
| 签署链接无法访问 | 系统设置中「部署域名」未填或与反代域名不一致 |
| 深色模式不生效 | 浏览器 localStorage 未保存，可在系统设置页重新应用一次主题 |
| 导入报「类型不存在」 | CSV 中 `case_type_code` 需与系统内类型编码一致（大写） |
