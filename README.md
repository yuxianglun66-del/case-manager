# 案件管理系统（法律服务专用）

> 面向法律服务公司（交通事故、工伤、意外险、学平险等理赔业务）的轻量案件管理系统。
> 集**案件全流程管理、电子合同签署、附件云端预览、费用业绩报表、自定义角色权限、通知与审计、数据备份**于一体，单机 Docker 一键部署，全中文界面，可完全内网运行。

---

## 一、核心优点

| 优点 | 说明 |
|------|------|
| **零代码业务定制** | 案件类型、自定义字段、状态流转全部后台可视化配置，新增业务线无需改代码 |
| **自带电子签章** | PDF/Word 模板上传 → 可视化拖拽签名位 → 一键发起，当事人点链接即可在线签名，单链接支持多人依次签署；发起前自动预检缺失变量，签署结果自动生成签署后 PDF |
| **自定义角色权限** | 内置超管/管理员/员工三级角色，支持**新建自定义角色**，18 项功能权限点逐项勾选；员工默认只见自己负责的案件 |
| **费用与业绩报表** | 独立报表页：按签单日期统计业绩、按发生时间统计收费，费用明细可追踪 |
| **通知中心** | 站内铃铛红点 + 企业微信推送（Webhook / 企业微信应用）双通道，签署完成、案件分配、状态变更等自动提醒，带重试与失败记录面板 |
| **数据安全留痕** | 登录与全量数据操作写入审计日志，超管可查改前/改后差异；登录失败自动锁定、会话滑动超时 |
| **一体化备份恢复** | 手动/定时自动备份、保留天数自动清理、一键恢复；恢复与备份均含上传文件 |
| **回收站机制** | 删除案件进回收站（软删除），可恢复或彻底删除，清理后编号可复用，签署流程自动阻断回收站案件 |
| **效率工具齐备** | Excel/CSV 批量导入导出（按当前筛选）、案件批量改状态/批量分配、待办提醒、统计看板、附件整案打包下载、全文搜索（含当事人/备注/历史） |
| **全中文 · 低依赖** | 前端资源全部本地 vendor（Bootstrap/Chart.js/PDF.js），无外网 CDN，断网可用 |
| **安全加固** | CSRF、CSP/安全头、参数化查询、登录/签署/找回密码限流、强口令策略、登录失败锁定、会话滑动超时、优雅停机 |
| **可运维监控** | app 容器健康检查 + 自动重启；内置运行状态面板（进程/数据库/LibreOffice/配置告警/推送健康度） |

## 二、技术栈

- **运行时**：Node.js 20（Docker Alpine）
- **框架**：Express（CommonJS）+ EJS 服务端渲染
- **数据库**：PostgreSQL 16（Docker 独立容器）
- **前端**：Bootstrap 5 + Bootstrap Icons + Chart.js + PDF.js（本地 vendor）
- **文档处理**：pdf-lib / pdfkit（PDF 签名与生成）、LibreOffice（Word/Excel 转 PDF 预览，含并发缓存与后台预转码）、exceljs（Excel 导入导出）
- **部署**：Docker Compose（app + db 两容器，含 healthcheck 与自动重启）

## 三、快速开始（Docker 部署）

### 1. 环境要求
- Linux 服务器（建议 Ubuntu 20.04+）或本机 Docker
- Docker 与 Docker Compose v2

### 2. 获取代码并配置
```bash
git clone https://github.com/yuxianglun66-del/case-manager.git
cd case-manager

cp .env.example .env
```
编辑 `.env`，**务必修改以下变量**（缺少任一必填项则容器启动失败，防止误用默认密钥）：

| 变量 | 说明 |
|------|------|
| `DB_PASSWORD` | PostgreSQL 密码（必填） |
| `SESSION_SECRET` | 会话加密密钥，32+ 位随机字符串（必填） |
| `ADMIN_PASSWORD` | 管理员初始密码，仅首次初始化生效（必填） |
| `APP_URL` | 对外访问地址（如 `https://case.example.com`），用于生成合同签署链接/找回密码等绝对 URL |
| `APP_PORT` | app 容器映射宿主端口，默认 3000 |
| `MAX_FILE_MB` | 单个附件上传上限（MB），默认 50 |
| `UPLOADS_DIR` | 上传文件存放目录（命名卷 `uploads` 或宿主机绝对路径） |
| `BACKUPS_DIR` | 备份文件存放目录（命名卷 `backups` 或宿主机绝对路径） |

### 3. 启动
```bash
docker compose up -d --build
```
- 首次启动自动建表、写入默认数据与内置角色，并生成合同模板占位 PDF
- app 容器含健康检查（`/healthz`），异常自动重启并标记 unhealthy

### 4. 首次登录
- 访问 `http://<服务器IP>:3000`
- 默认账号：**admin**，密码为 `.env` 中 `ADMIN_PASSWORD` 预设值
- 登录后系统会要求修改自身密码

### 5. 部署域名
登录后进入 **系统设置 → 品牌与主题 → 部署域名** 填写对外地址（或 `APP_URL`），用于生成合同签署链接等绝对 URL。

### 6. Nginx 反向代理 + HTTPS（推荐）
```nginx
server {
    listen 443 ssl http2;
    server_name case.example.com;
    ssl_certificate     /etc/letsencrypt/live/case.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/case.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
        client_max_body_size 100M;   # 需 ≥ MAX_FILE_MB
    }
}
```
Caddy 一键 HTTPS 方案见 `DEPLOY.md`。

## 四、操作指南

### 菜单结构
- **业务办理**：工作看板 / 案件管理 / 费用报表 / 法律法规库 / 回收站
- **系统管理**（按权限显示）：用户管理 / 系统设置 / 运行状态 / 备份与恢复 / 操作日志（后三者仅超管）

### 1. 工作看板
- 顶部统计卡：案件总量 / 待受理 / 处理中 / 结案归档
- 柱状图按案件类型、环形图按状态统计；管理员可见员工办案量排行
- **待办提醒**：自动列出「已逾期 / 今天到期 / 未来 N 天内到期」的流程提醒，点击确认完成

### 2. 案件管理
- **列表页**：单卡片工具条 —— 状态页签（全部/待受理/处理中/诉讼中/已结案归档）+ 可折叠筛选（案号/名称/客户关键词全文搜索、类型、状态、服务人员、签单日期区间）+ 可折叠批量操作（勾选后自动弹出，支持批量改状态、批量分配负责人）
- **导入导出**：按当前筛选一键导出 Excel/CSV（含当事人、目标金额、已收金额、费用笔数汇总列）；标准模板批量导入
- **详情页分区**：基本信息 + 自定义字段、当事人（一案多人）、附件、合同、进度时间线、下一步流程
- **全文搜索**：案号、名称、客户、当事人、备注、自定义字段、历史操作均可命中和筛选

### 3. 电子合同签署（核心流程）
1. **上传模板**：系统设置 → 合同模板（支持 PDF / Word）
2. **设置签名位**：可视化编辑器拖拽签名框，绑定签署角色；文本字段可插入 `{name}` `{id_card}` `{address}` 等当事人变量，签署时自动填充
3. **发起前预检**：点击发起时自动校验模板变量与当事人信息，缺失/留空项弹出警告（可确认空值留白继续）
4. **发起签署**：案件详情 → 合同 → 生成签署链接；列表内嵌「复制链接」按钮，撤回后一键「重新发起」生成全新 7 天有效链接，旧链接失效
5. **对方签署**：链接免登录，同一链接内多人**依次手写签名**；签署完成自动生成签署后 PDF，并推送企微 + 站内通知跟进存档
6. **下载归档**：可下载原合同与签署后 PDF，全程进度可查

### 4. 费用与业绩报表
- 独立报表页，按签单日期统计业绩、按费用发生时间统计收费
- 费用明细可追踪到具体案件，列表汇总目标金额/已收金额/费用笔数

### 5. 回收站
- 案件「删除」进入回收站（软删除），可在回收站恢复或彻底删除
- 彻底删除后释放案号，供新案件复用；被删除案件的签署链接自动失效

### 6. 用户、角色与权限
- **用户管理**（管理员）：新建（含用户名、姓名、角色选择）、编辑、停用、彻底删除（案件可改派）、重置密码、密保问题
- **角色与权限**（仅超管）：角色权限面板支持**新建/编辑/删除自定义角色**（内置角色不可改删），18 项权限点逐项勾选：
  - 案件：查看 / 查看全部 / 新建 / 编辑 / 删除与回收站 / 指派 / 提醒 / 收费 / 批量操作 / 导入导出
  - 当事人 / 附件（上传/替换/删除）/ 合同签署
  - 报表：费用报表查看
  - 法律法规库管理
  - 系统：用户管理 / 角色权限 / 系统参数
- **登录安全**：密码 bcrypt、连续 5 次失败锁定 15 分钟、登录限流、会话 60 分钟滑动超时、找回密码走密保问题

### 7. 通知中心
- 站内右上角铃铛：未读红点 + 数字角标，轮询自动刷新，支持单条/全部已读
- 企业微信推送：Webhook 或企业微信应用双通道；事件含案件分配、状态变更、流程提醒、新增附件、合同签署
- **推送记录**面板：时间/目标/事件/渠道/结果/重试次数/错误信息，可手动清理 30 天前记录；推送失败自动重试

### 8. 附件在线预览
- 图片缩略图墙 + 灯箱（缩放/旋转）；PDF 内嵌渲染；Word/Excel 自动转 PDF 预览（并发去重缓存，上传后后台预转码）
- PDF 以 base64 内嵌直喂渲染引擎，规避浏览器扩展/安全软件对接口请求的拦截；失败自动回退浏览器原生 iframe

### 9. 法律法规库
- 富文本（Quill）/ Markdown 内容 + 分类 + 附件，支持在线预览与下载，可按分类/关键词检索

### 10. 系统设置（管理员）
- 案件类型与自定义字段、案件状态（分类/颜色/排序）、品牌与主题（亮/暗/跟随系统 + 多套配色）、公司名称 / Logo / 部署域名、合同模板、通知推送开关

### 11. 备份与恢复（仅超管）
- 手动「立即备份」生成 JSON 快照（数据库 + 上传文件），可下载、恢复、删除
- 自动备份：开关、频率（每日/每周）、执行时间、保留天数自动清理

### 12. 运行状态（仅超管）
- 进程信息（运行时长/内存/Node 版本）、PostgreSQL 版本连通性、LibreOffice 可用性、容器健康检查状态
- **配置告警**：部署域名未设、会话密钥为默认值、推送/备份未启用等提示；近 7 天推送失败统计、案件总数/待办数一览

### 13. 操作日志（仅超管）
- 登录与全量数据变更记审计，支持用户/操作类型/日期/关键词筛选，可展开查看改前/改后差异
- 日志保留期可设（3/7/30/90 天或不清理），每日自动清理

## 六、常用维护

```bash
# 查看日志
docker compose logs -f app

# 升级（拉取最新代码后重建）
git pull
docker compose up -d --build

# 查看健康状态
docker compose ps

# 数据库手动备份
docker exec $(docker compose ps -q db) pg_dump -U casemgr casemgr > backup_$(date +%F).sql
```

> 日常请优先使用系统内的「备份与恢复」功能，它包含数据与上传文件，且支持定时自动备份。
> 服务器配置只改 `~/.env`，不要改动 `docker-compose.yml`（否则升级时 `git pull` 会被本地修改挡住）。
> 升级后若附件/PDF 提示文件不存在，检查 `UPLOADS_DIR` 是否正确指向历史数据目录。

## 七、常见问题

| 现象 | 原因 / 处理 |
|------|------|
| 登录后跳回登录页 | `.env` 中 `SESSION_SECRET` 不一致，或 Nginx 未配置 `proxy_set_header Host $host` |
| 容器启动失败提示缺环境变量 | `.env` 未配置 `DB_PASSWORD` / `SESSION_SECRET` / `ADMIN_PASSWORD` |
| 附件上传 413 | Nginx `client_max_body_size` 需 ≥ `MAX_FILE_MB` |
| 签署链接无法访问 | 系统设置中「部署域名」/ `APP_URL` 与反代域名不一致 |
| PDF 在线预览失败 | 浏览器扩展/安全软件拦截 `/api/` 请求；已内置 base64 内嵌直喂与 iframe 兜底，仍异常请排查客户端拦截规则 |
| 导入报「类型不存在」 | CSV 中 `case_type_code` 需与系统内类型编码一致（大写） |
| 深色模式不生效 | 浏览器 localStorage 未保存，可在系统设置页重新应用一次主题 |
